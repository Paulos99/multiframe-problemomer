# Проблемомер MultiFrame: документация для передачи

Адрес боевого сервиса: **https://stp-multiframe.ru/problemomer/**
Проверочный стенд владельца: https://paulos99.github.io/multiframe-problemomer/

Этот набор документов нужен команде интернет-маркетинга, которая размещает Проблемомер на сайте `stp-multiframe.ru`.
Код вы **не правите**: изменения вносит владелец через репозиторий `Paulos99/multiframe-problemomer`.
Вы получаете проверенный выпуск (метку `vX.Y.Z` на ветке `main`) вместе с готовым архивом и устанавливаете его одной командой.

## Что это

Проблемомер — набор **статических файлов** (страница, скрипты, картинки, звуки), приложение React + Vite с режимом PWA
(устанавливается на экран телефона). Серверной части, базы данных, входа и личных кабинетов **нет**. Персональные данные
(имя, телефон, почта) в Проблемомере не собираются. Для работы нужен только веб-сервер, который отдаёт файлы по адресу `/problemomer/`.

```
Браузер ──HTTPS──▶ nginx stp-multiframe.ru ── /problemomer/ ──▶ папка выпуска (index.html, assets/, audio/, sw.js …)
                                          ── /calc/        ──▶ калькулятор (отдельный репозиторий Paulos99/MF_StP)
Браузер ──▶ mc.yandex.ru                    (Метрика, только если задан VITE_YM_ID и пользователь согласился на cookies)
Браузер ──▶ приёмник аналитики (Google Apps Script, только если задан VITE_ANALYTICS_INGEST_URL)
```

Проблемомер ссылается на калькулятор (кнопка и QR-код в PDF): по умолчанию `https://stp-multiframe.ru/calc/`.

## Два окружения

| | Стенд владельца (Павла) | Боевой: https://stp-multiframe.ru/problemomer/ |
|---|---|---|
| Где | GitHub Pages, подпапка `/multiframe-problemomer/` | сервер команды интернет-маркетинга |
| Кто видит | владелец | пользователи |
| Как обновляется | автоматически при каждом изменении `main` | вы ставите выпуск по метке (см. [DEPLOY.md](DEPLOY.md)) |
| Адрес и путь в сборке | `VITE_BASE_PATH=/multiframe-problemomer/` (задаёт рабочий процесс стенда) | по умолчанию `/problemomer/` |
| Общие секреты | нет: у стенда и у боевого сервера свои настройки | |

## Владелец и контакты

- Код, метки выпусков и репозиторий находятся у владельца: https://github.com/Paulos99/multiframe-problemomer.
  У команды нет доступа на запись и он не нужен.
- Вопрос по сайту или новая версия — [Issues](https://github.com/Paulos99/multiframe-problemomer/issues) репозитория или сообщение владельцу напрямую.
  Контакт владельца: **[заполнит владелец перед передачей: имя, почта, мессенджер]**.
- Решения по тексту, шкале комфорта и ориентирам в дБ принимает владелец, не команда размещения (см. [../comfort-scale.md](../comfort-scale.md)).
- Доступа к вашему серверу у владельца нет; всё, что требуется от вас, описано в [DEPLOY.md](DEPLOY.md).

## Что команда делает и чего не делает

Делает: ставит выпуски, настраивает nginx и HTTPS, хранит свои значения `VITE_YM_ID` / `VITE_ANALYTICS_INGEST_URL`
(сообщает владельцу, см. [ENV.md](ENV.md)), следит за статистикой, откатывает выпуск при проблеме.

Не делает: не правит файлы сайта на сервере и в репозитории, не собирает сайт из непроверенных веток, не публикует
ключи и значения секретов в чатах.
