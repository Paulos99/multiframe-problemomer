# Чек-лист безопасности перед открытием для пользователей

Проблемомер — статический сайт без входа, базы данных и ввода персональных данных, поэтому риск ниже, чем у кабинета.
Отметьте пункты. Результат проверки репозитория владельцем — в разделе «Что проверено» ниже.

## Сервер и сеть
- [ ] Сайт открывается только по **HTTPS** (сертификат действителен, HTTP перенаправляет на HTTPS).
- [ ] Включён `Strict-Transport-Security: max-age=31536000` (после проверки, что HTTPS работает на всём сайте; для поддоменов решайте отдельно).
- [ ] Каталог выпусков `.releases/` не отдаётся наружу: nginx отдаёт только `/problemomer/…` (проверьте `https://stp-multiframe.ru/.releases/` → 404).
- [ ] Листинг каталогов выключен (`autoindex off`, по умолчанию).
- [ ] Права на файлы выпуска — только чтение для пользователя nginx; запись только у того, кто ставит выпуски.
- [ ] Сервер обновляется (ОС, nginx); доступ по SSH — по ключам, вход под root запрещён.
- [ ] Доступ к серверу и к ссылке `problemomer` есть только у людей, ставящих выпуски.

## Заголовки
- [ ] `curl -I https://stp-multiframe.ru/problemomer/` показывает `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `Content-Security-Policy-Report-Only`
      (файл `deploy/nginx/security-headers.conf`).
- [ ] `index.html`, `sw.js`, `manifest.webmanifest`, `version.txt` отдаются с `Cache-Control: no-cache` (или строже), `assets/*` — с `immutable`.
- [ ] Политика CSP сейчас в режиме наблюдения. На выпуске проверена: нарушений нет. Перевод в рабочий режим (`Content-Security-Policy`) —
      по решению владельца после недели наблюдения в консоли браузера; усиление (убрать `'unsafe-inline'`) требует правки кода, это выпуск владельца.

## Данные и секреты
- [ ] В репозитории и в архиве выпуска нет паролей и ключей (проверено владельцем, см. ниже). Значения `VITE_*` в сборке — публичные по природе.
- [ ] Значения для секретов репозитория (`PROD_VITE_YM_ID`, `PROD_VITE_ANALYTICS_INGEST_URL`) передаются владельцу не через общий чат.
- [ ] Приёмник аналитики (таблица Google) принимает только запись анонимных строк; таблица закрыта для посторонних, доступ у ограниченного круга.
- [ ] Ссылка на веб-приложение приёмника не публикуется в открытых местах, кроме сборки сайта (где она по необходимости видна).
- [ ] Страница `privacy.html` актуальна, баннер cookies показывается, если задан `VITE_YM_ID` (проверьте в инкогнито).
- [ ] Метрика: в коде вебвизор выключен (`webvisor: false`); не включайте его и запись форм в настройках счётчика. В Проблемомере форм со вводом данных нет.

## Проверки руками после установки
- [ ] Проходит весь сценарий, PDF скачивается, «Поделиться» работает.
- [ ] Сайт работает с включённым сервис-воркером и без него (первый заход, повторный заход, режим «офлайн» открывает ранее посещённые экраны).
- [ ] `https://stp-multiframe.ru/problemomer/?area=999999` и другие странные параметры не ломают страницу.
- [ ] Откат проверен хотя бы раз на тестовом пути до открытия сайта ([DEPLOY.md](DEPLOY.md)).
